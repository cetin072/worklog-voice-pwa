# Mock Call Review V1

유료 STT/AI 연결 전, 실제 사용자 흐름을 끝까지 검증하기 위한 로컬 전용 모의 처리 화면이다.

## 범위
- 통화 선택 후 모의 STT/AI 처리
- 처리중 상태 표시
- 모의 녹취록 표시
- 요약 / 핵심내용 / 할 일 / 일정 / 후속조치 / 결정사항 / 연락처 후보 표시
- 각 항목 포함/제외
- 텍스트 수정
- 일정 후보 확인
- 최종 저장 시 실제 DB 대신 로컬 mock 저장 완료 상태 표시

## 안전
- 외부 API 호출 금지
- 녹음파일 서버 전송 금지
- API 키 불필요
- Supabase/Notion 쓰기 금지
- 유료 기능 잠금 유지

## 목적
실제 STT 업체를 연결하기 전에 화면과 검수 흐름을 확정한다. 이후 실제 엔진은 동일한 내부 분석 계약을 사용해 교체한다.
