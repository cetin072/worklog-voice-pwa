# Mobile navigation/discoverability QA finding

실기기 QA에서 Calendar/Notification/업무 기능이 코드에는 존재하지만 사용자가 찾을 수 있는 메뉴/탭이 없어 사실상 접근 불가함을 확인.

필요 조치:
- 인증 후 상시 접근 가능한 하단 내비게이션 또는 동등한 메뉴 제공
- 홈 / 업무 / 일정 / 설정 최소 4개 진입점
- 일정 화면에서 오늘/다가오는 일정과 Calendar/Notification 액션을 직접 노출
- 일정이 0건이어도 기능 위치와 다음 행동을 설명
- 업무 화면에서 검색/상세/상태변경을 명시적 메뉴로 노출
- 현재 기능을 `전체 보기` 내부에 숨기지 않기

최종 실기기 QA 전 해결 필요.
