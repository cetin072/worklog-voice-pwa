# 습관 V1 검증

기존 mobileTheme와 Seoul 날짜/주 계산을 재사용. 매일/지정 요일/주 N회 등록, 이번 주 달성 횟수, 하루 체크/실행 취소, 상세 수정과 종료를 구현했다. 반복업무 완료와 별개 테이블이며 미달성 일을 업무로 생성하지 않는다. 세 영역을 연결할 작은 내 관리 선택 컴포넌트도 포함한다. 독립 PR에서는 화면 모듈만 제공하고 앱 진입 연결은 통합 QA 소스에서 수행한다.

- 실제 PGlite SQL에서 체크 10회 동일 요청 → 하루 한 행, 취소, stale 버전 충돌, 지난 주 이력 유지, 종료 후 이력 유지, 타인/anon 격리를 실행했다.
- 실제 저장 함수에서 응답 유실 뒤 동일 요청 영수증 읽기, JSON 키 순서 차이, 확인 불가 오류를 검증했다.
- 실제 TSX+가짜 native host 검사: 10회 빠른 터치 요청 한 번, 확인 후 횟수 변경, 취소, 실패 시 성공 표시 없음.
- Node 전체 1182/1182, TypeScript PASS. Android Metro export PASS는 기본 엔트리 번들 검사이며 이 단독 PR에 앱 진입 연결이 없어 습관의 기기 실행 증거가 아니다.
- 신규 습관 migration은 격리 로컬 DB만 실행했다. 원격 데이터 조회/수정·migration 적용·APK·Production/Play 배포 없음.

남은 검수: 세 기능 통합 소스의 320/390 렌더링, 재시작/계정 전환/오프라인 실패를 포함한 Android 실행과 글꼴 배율. 과거 체크는 보존되며 V1에는 별도 통계나 연속 기록 화면이 없다. 목록 500/한 주 체크3500건 경계는 전체 확인 불가 오류로 처리한다.
