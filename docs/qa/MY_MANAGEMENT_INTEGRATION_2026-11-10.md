## 구조·데이터 안전

새 유료 API, AI 호출, 별도 서버, 런타임 의존성 추가 없음. 공유 범위는 날짜·행 스타일·화면 선택 정도이며 정기지출 납부/반복 회차/습관 체크의 저장 의미를 분리했다. 90일 미래 회차를 DB에 미리 만들지 않는다. 일반 체크에는 확인 팝업이 없고 종료/미래 전체 수정만 확인한다.

기존 적용 migration은 읽기 전용으로 확인했다. 최초 구독 migration 파일명을 실제 적용 버전 `20261109125845`와 맞췄으며 재적용하지 않았다. 결제수단 `20261109144344`도 기존 적용 상태를 보존한다. 새 아래 세 파일은 **코드와 격리 DB만** 준비했다.

- `20261109232907_regular_expenses_v1.sql`
- `20261109233147_repeating_work_v1.sql`
- `20261109234334_habits_v1.sql`

해지·종료는 과거 이력을 보존한다. 새 FK cascade는 명시적 계정 삭제가 기존 계약대로 동작하는지 격리 DB에서만 검증했다. 기존 사용자 데이터 삭제·변환은 하지 않았다. 신규 스키마가 없는 원격 환경에서 확장 기능은 준비 중/확인 필요로 표시되며 현재 운영 사용 준비 완료 상태가 아니다.
