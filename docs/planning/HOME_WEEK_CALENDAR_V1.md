# 홈 첫 화면 — 승인된 주간 일정·오늘 업무안

2026-11-09 사용자 목업 승인, Issue #530. 홈 화면에 한정한다. 기능·효율 전수검사 #494의 나머지 신규 개발 보류는 유지한다.

큰 브리핑 현황 타일과 입력 도구를 지나 실제 일정을 확인하던 구성을 날짜·한 줄 요약 → 주간 날짜와 선택일 일정 → 업무 목록 → 메모·입력 도구로 바꾼다. 기본 주간 보기, 월 보기는 같은 카드 안에서 펼침. 날짜 선택은 일정만 바꾸며 업무 목록은 본래 기한 필터를 유지한다. 오늘 업무가 없으면 기존의 첫 비어 있지 않은 기한 그룹을 보여주고, 전체 보기에서 사용자가 다른 기한을 선택할 수 있다.

업무는 제목과 오른쪽 완료 버튼으로 시작한다. 완료 버튼은 기존 완료/실행 취소 경로를 쓰고 제목을 누르면 기존 수정·삭제 확인·상세·재알림·Google 내보내기 기능을 펼친다. 검색·설정·회의 녹음·직접 입력·캡처 진입을 보존한다. 기존 고정 Quick Voice와 녹음 중 이동 보호 및 하단 여백은 유지한다. 목업의 음성 버튼 그림을 새로운 녹음 동작으로 교체하지 않는다.

## 일정 데이터와 실패 경계

- 최신 main #528의 `personalCalendarRequest(get_my_calendar_month)`를 재사용한다. 승인·병합된 ERP #621의 기존 `worklog.schedules` 조회이며 새 테이블·RPC·알림·저장·계정 통합을 만들지 않는다. 회사 공지는 기존 업무수첩과 동일하게 포함하지 않는다.
- 표시 주간이 월 경계를 넘으면 두 달을 조회한다. 각 월 결과가 오늘 일정을 함께 반환해도 ID별 한 번만 표시한다. 한국 날짜, 기간 겹침, 종일 종료일 제외를 적용한다.
- 첫 로드/다시 조회/부분 결과/오류와 빈 목록을 구분한다. RPC 실패 시 기존 브리핑에서 확인된 일정은 계속 표시하며 월 전체가 비어 있다고 판정하지 않는다. 비통합 계정은 브리핑의 제한된 범위를 명시한다.
- 본인 검증 토큰과 기존 `current()` 소유권 경계를 재사용한다. 컴포넌트는 계정별 key로 분리하고 조회 키/해제 경계를 추가해 이전 계정·이전 달의 늦은 응답을 버린다. 홈 복귀·브리핑 갱신·포그라운드에서 재조회한다.
- 기존 브리핑에 있는 일정은 펼쳐 기존 알림/내보내기 제어를 이용한다. 개인 일정 상세는 기존 내 캘린더 편집기로 연결하고 선택한 달/날짜를 넘긴다. 미설치 RPC는 준비 중으로 안내하고 운영 DB를 자동 변경하지 않는다.

## 검수 및 반영

TypeScript, 실제 Home TSX 및 캘린더 TSX 상태/이벤트 검사, 날짜·기간 모델, 기존 모바일 회귀검사, Android Metro export를 실행한다. 로컬 Chromium은 `socket() failed: Operation not permitted`로 실행이 막혀 실제 320/390px 렌더·글자 확대·Android 터치는 확인하지 못했다. 자동검사 성공을 실기기 QA 또는 시간 절감 실측으로 표현하지 않는다.

미병합 변경은 앱 패치노트에 표시하지 않는다. main 병합 시 사용자 체감 변경을 로컬 패치노트에 갱신한다. 이번에는 Draft PR을 제공하고 APK 생성·Play 제출·Production 배포·운영 데이터 쓰기를 실행하지 않는다. 기존 방식 대비 시간 절감은 아직 미측정이다.

## 실기기 피드백 반영 — 2026-11-09

사용자는 나머지 홈 구도를 유지하고 체크박스를 명시적인 완료 버튼으로 교체하도록 요청했다. 업무 아래 알림 설정과 Google 연결/Google에 추가를 상시 표시한다. 알림의 예약 확인 필요·미설정·권한 필요·실제 예약 시점은 별도로 구분한다. 펼친 업무에서 같은 바로가기를 중복 표시하지 않는다. Google 미연결/만료 시 기존 설정 화면으로 이동하며 OAuth와 실제 일정 추가는 각 기존 명시적 버튼에서만 실행한다. 연결 버튼을 누르는 것만으로 인증·알림 예약·외부 일정 생성이 실행되지 않는다. 기존 수정/삭제 확인·완료 취소·일정·필터·입력·도크는 유지한다. APK는 이번 피드백으로 자동 재생성하지 않는다.

추가 피드백: Google 연결은 설정에만 남기고 홈 업무의 Google 버튼을 제거했다. 일정의 알림은 기존 확정 날짜·시각 저장 시 자동 시작 알림 정책을 유지하며, 목록에는 큰 설정 버튼 대신 작은 한 줄 상태를 표시한다. 상태를 누르면 기존 개별 변경 화면이 열린다. 미확인 상태를 예약됨으로 추정하지 않으며, 자동 예약·권한·시각 없는 일정의 정책은 변경하지 않는다.
