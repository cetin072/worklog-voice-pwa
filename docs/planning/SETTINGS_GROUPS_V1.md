# 설정 카테고리 정리 V1 — 2026-11-09

사용자 요청: 설정에서 자주 찾는 기능을 위에, 앱 정보·계정·로그아웃은 아래에 둔다. 설명을 줄이고 카테고리별 블록을 명확하게 나눈다. 태장 출근앱에도 같은 표현 방식을 독립적으로 적용한다.

## 업무수첩 순서

| 블록 | 항목 |
|---|---|
| 기록 | 업무일지, 과거 업무 검색 |
| 알림 | 알림·리마인더 |
| 외부 연결 | Google 캘린더 |
| 앱 정보 | 업데이트·패치노트, 개인정보처리방침, 앱 종류·버전 |
| 계정 | 로그인 계정, 계정 및 데이터 삭제 요청, 로그아웃 |

## 표시 원칙

- 제목 아래 한 카드로 같은 종류의 항목을 묶고, 항목은 56px 이상 터치 영역과 짧은 제목을 사용한다.
- 반복 영문 라벨·기능 제목을 다시 설명하는 문장을 앞 화면에 나열하지 않는다.
- 연결 상태·만료·진행 중·오류는 생략하지 않는다. Google 캘린더의 권한·계정·일정 추가 범위 설명은 기존 연결 안내에 보존한다.
- 앱 업데이트 안내의 상세 도움말은 패치노트 화면에서 확인한다. 설정 목록의 Data Core 내부 상태 문구는 표시하지 않는다.
- 계정과 로그아웃은 마지막 블록이다. 기존 로그아웃 확인·정책 링크·오류 처리와 인증 계약은 변경하지 않는다.
- 향후 실제 구현된 Notion 등 연결 기능은 외부 연결에 추가한다. 미구현 연결 버튼이나 준비 중 항목을 먼저 만들지 않는다.
- 태장 앱은 같은 그룹/행 표현을 자체 파일에 복제·적응한다. 앱 간 런타임 의존이나 범용 설정 프레임워크를 추가하지 않는다. 브랜드 색상과 각 앱의 기능은 유지한다.

## 적용 및 검증 범위

- 별도 설정 정리 PR로 준비한다. 통합 QA #525의 확정 SHA 및 이미 제공한 APK는 변경하지 않는다.
- 모바일 관련 회귀검사, TypeScript, Android Metro bundle로 기능 연결·코드 구성을 검증한다.
- 로컬 화면 캡처용 Chromium 실행은 환경의 socket 제한으로 실패했다. 화면 구조 HTML은 현재 JSX/스타일을 사용한 합성 미리보기이며 실기기 화면 검수 근거가 아니다. 320/390px 실제 렌더·글자 확대·터치 검수는 남아 있다.
- 요청 없는 새 QA APK·정식 배포·Play 제출 및 운영 데이터 쓰기는 하지 않는다.
