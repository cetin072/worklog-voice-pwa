# STT 연결 준비 체크리스트 V1

실제 유료 STT 연결 직전에 확인할 항목이다.

- [ ] STT 공급자 확정
- [ ] 공급자 최신 파일 크기/길이/MIME 한도 확인
- [ ] 서버측 API 키 등록
- [ ] 개발자 2인 유료 승인 충족
- [ ] 임시 업로드 저장소 확정
- [ ] 원본 음성 영구 저장 안 함
- [ ] 성공 후 즉시 삭제 / 실패 시 최대 24시간 삭제 상한
- [ ] STT 결과 체크포인트 저장
- [ ] AI 결과 체크포인트 저장
- [ ] 재시도 시 성공 단계 재호출 금지
- [ ] usage_events 중앙 기록 경로 활성화
- [ ] 통화 보고서 + 할 일 + 일정 + 후속조치 단일 분석 결과 계약 확인
- [ ] 사용자 일정/할 일 자동 확정 금지
- [ ] 실제 음성 3~5건 STT 정확도 검증 계획 확정

이 문서는 준비상태를 설명하는 체크리스트일 뿐 실제 유료 호출을 활성화하지 않는다.
