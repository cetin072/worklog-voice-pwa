# 통화 보고서·STT 연결 직전 기준 V1

## 목표
실제 STT 공급자를 연결하기 전까지 업무수첩의 통화 처리 UX·데이터 계약·안전 게이트를 완성한다.

## 최종 사용자 흐름
통화녹음 선택 → 분석 준비 → STT → 전체 녹취 → AI 구조화 분석 1회 → 통화 보고서 + 할 일/일정/후속조치 → 사용자 확인 → 저장 → 임시 음성 삭제

## 통화 보고서 구조
- 한 줄 요약
- 통화 개요
- 주요 논의사항
- 상대방 요청사항
- 내가 약속한 사항
- 결정사항
- 확인 필요사항
- 전체 녹취록(접기)

보고서와 할 일/일정은 같은 AI 분석 결과에서 생성한다. 보고서용 AI 호출을 별도로 추가하지 않는다.

## STT 연결 전 필수 준비
- STT 공급자 결정
- 공급자 파일 크기/길이/MIME 한도 최신값 확정
- 서버측 API 키 등록
- 2인 유료 승인 게이트 충족
- 임시 업로드 저장소 확정
- 업로드 → STT → 체크포인트 → 분석 → 저장 → 삭제 경로 smoke test
- usage_events 기록 경로 활성화
- 실패/재시도 시 STT 중복 호출 방지 확인

## 현재 안전 경계
- 실제 STT/AI 네트워크 호출 금지
- API 키 저장소 커밋 금지
- 원본 음성 영구 저장 금지
- 사용자 일정/할 일 자동 확정 금지
- main 병합은 사용자 명시 승인 전 금지
