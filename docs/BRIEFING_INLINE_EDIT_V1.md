# 브리핑 간단 수정 V1

브리핑 2.0에서 보이는 업무명의 사람 이름·회사명·일반 오타를 빠르게 바로잡는 기능이다.

## 범위

- 각 브리핑 업무에 `✏️` 수정 버튼 제공
- 업무명만 간단 수정
- 저장 시 연결된 Notion 페이지의 `업무명` 속성도 즉시 수정
- `음성원문`과 `내용`은 자동 덮어쓰기하지 않아 원기록을 보존
- 수정 대상 페이지가 현재 연결된 데이터소스 소속인지 서버에서 확인
- 브리핑의 완료/실행취소/분류/카카오 로직은 변경하지 않음

## 후속 확장 후보

실사용에서 필요가 확인되면 담당자·기관 등 다른 필드 편집을 별도 단계로 추가한다.
