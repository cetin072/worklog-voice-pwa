# 음성 일정 추출 + 메모 정리 V1

음성 업무 기록에서 날짜·시간 표현은 Notion `기한`으로 구조화하고, 브리핑에 쓰이는 `업무명`과 `내용`에서는 해당 표현을 제거한다.

예시:

- 음성원문: `내일 오후 3시에 범한메카텍 김대리에게 전화`
- 기한: `2026-09-13 15:00` (Asia/Seoul)
- 업무명/내용: `범한메카텍 김대리에게 전화`
- 음성원문: 원문 그대로 보존

V1 인식 범위:

- 오늘 / 내일 / 모레 / 글피
- `9월 15일`, `2026년 9월 15일`
- 이번 주 / 다음 주 + 요일
- 오전/오후/아침/저녁/밤 + 시각
- 10~23시 형태의 24시간 시각
- 정오 / 자정

모호한 한 자리 시각(예: `3시`)은 오전/오후를 임의 추정하지 않는다. 날짜만 구조화하고 `3시` 표현은 본문에 남긴다.

사용자가 화면에서 직접 `기한` 날짜를 지정한 경우에는 그 값을 우선하고 본문 자동 정리를 수행하지 않는다.
