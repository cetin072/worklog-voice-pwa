## Android 로그인·화면 여백 보완

- Android 로그인에서 키보드가 비밀번호 입력과 로그인 버튼을 가리지 않도록 입력 화면을 키보드 높이에 맞춰 이동·스크롤합니다.
- 휴대폰 상단 상태 표시줄과 하단 시스템 내비게이션 영역에 앱의 버튼·텍스트가 겹치지 않도록 화면 여백을 적용합니다.
- 업무 탭에서 현재 브리핑뿐 아니라 과거·완료 기록을 업무명·기관·후속조치·원문 기준으로 검색할 수 있도록 전체 기록 검색을 추가합니다.
- 전체 기록 검색은 기존 인증·RLS 경계를 유지하며 상태 조건과 결과 더 보기를 제공합니다.
- 일정 취소는 업무 기록을 지우지 않고 취소 상태로 전환하며, 연결된 휴대폰 Calendar 이벤트와 알림도 함께 정리합니다.
- 이미 연결된 일정을 다른 Google Calendar로 옮길 때 이전 Calendar에 중복 일정이 남지 않도록 동기화 방식을 보완합니다.
- 빠른 음성메모는 파일 저장 완료와 업무 기록 등록 상태를 분리해 보여주며, 파일 저장 후 업무 직접 입력으로 이어갈 수 있습니다.
- 이 기록은 PR #339 개발 브랜치의 변경 기록입니다. 실제 사용자용 패치노트에는 main 병합 후 완료 기능만 반영합니다.
