# 폴더 이름 입력 시 키보드 가림 수정

업무 탭의 긴 카드 중간에 있던 폴더 이름 편집기를 작은 모달 편집창으로 이동. Android Modal은 기존 RN의 adjustResize를 사용하고 iOS에서만 KeyboardAvoidingView padding을 적용한다. 스크롤 가능한 편집창에 입력·저장·취소·저장 오류를 함께 표시하며 onShow에서 입력에 초점을 둔다. 뒤의 홈/업무 탭은 모달 뒤에 남으므로 폴더 입력 창의 공간을 차지하지 않는다.

기존 저장 경계·부모 폴더·버전 검증을 재사용. 저장 실패 시 이름 보존, 저장 중 중복 제출/뒤로 닫기 차단, 빈 이름 제출 차단. 키보드 완료 버튼으로도 저장 가능.

검증: 폴더 runtime 8개 및 TypeScript 통과. 실제 휴대폰 키보드 높이·글자 확대·취소 후 탭 복원 검수는 미완료. APK·DB·Play 변경 없음.
