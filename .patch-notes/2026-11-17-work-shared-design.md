# 업무 탭 음성 등록과 홈 디자인 통일

- 홈/업무에서 동일한 VoiceRecorderCard 한 개와 저장·알림·새로고침 흐름을 사용한다. 음성 내용에서 소유한 폴더 이름이 정확히 하나 일치하면 기존 폴더 RPC로 자동 배정한다. 여러 후보/동명/부정 표현은 자동 배정하지 않는다. 비슷한 발음은 추측하지 않는다. 캘린더 일정과 여러 건의 분할 저장은 자동 폴더 배정에서 제외한다.
- 저장 확정 이후에만 폴더 배정을 시도하며 실패를 저장 실패로 취급하지 않는다. version -1 조건으로 이미 정리된 기록을 덮어쓰지 않고 계정 전환 후 쓰기를 차단한다.
- 녹음·전사·미확정 저장 중 어느 탭에서도 다른 화면 이동을 막는다.
- 새로고침은 제목 행 우측의 텍스트 버튼으로 배치한다.
- workspaceStyles를 홈/업무가 공유: 카드, 제목, 헤더 정렬, 새로고침, 링크, 필터. 기록 글자 스타일도 기존 recordRowStyles를 재사용한다. 개별 탭에 같은 값의 복사본을 두지 않는다.
- 큰 검은 등록 버튼을 직접 입력 링크로 바꾸고, 폴더 조작 버튼은 밝은 테두리 형식으로 정리한다.

검증: 홈/업무 실제 JSX 음성 저장·새로고침 실행, 양쪽 탭 녹음 보호, 폴더/공통 스타일, 기존 음성 중복 저장 방지 검사 통과. TypeScript 통과. 실제 휴대폰 음성·화면 검수는 미완료. APK/DB/Play 변경 없음.
