## 모바일 일정·알림 UX 개선

- 휴대폰의 Google 계정 캘린더를 포함한 쓰기 가능한 캘린더를 사용자가 직접 선택하고, 선택한 캘린더를 기억해 일정 동기화에 재사용하는 작업을 진행합니다.
- 일정 알림을 시작 시각뿐 아니라 5분·10분·30분·1시간·1일 전 등 여러 시점에 복수 설정하고 개별 또는 전체 취소할 수 있도록 개선합니다.
- 알림으로 일정 화면을 연 뒤 앱을 일반 실행했을 때 이전 알림으로 반복 진입하지 않도록 cold-start 처리도 함께 보강합니다.
- 이미 동기화한 일정을 다른 캘린더로 옮길 때 이전 이벤트를 제거하지 못하면 새 이벤트를 되돌리고, 되돌리기도 실패한 경우 다음 앱 실행에서 정리하도록 보강합니다. 중복 일정이 남는 것을 막기 위한 개발 중 안전장치입니다.
- 이 기록은 PR #339 개발 브랜치의 변경 기록이며, 실제 사용자용 패치노트에는 main 병합 후 완료 기능만 반영합니다.
