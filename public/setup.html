처음 1회 설정

내 Notion으로 시작하기

약 3분이면 끝납니다. 한 번 연결하면 다음부터는 업무수첩만 열어 바로 기록하면 됩니다.

중요: 연결 정보는 지금 사용하는 기기의 브라우저에 저장됩니다. 휴대폰에서 업무수첩을 쓸 예정이면 이 설정 화면은 그 휴대폰에서 열어두고 2~4단계를 진행하세요. 1번의 Notion 토큰 만들기만 PC에서 해도 됩니다.

이 기기는 이미 Notion과 연결되어 있습니다.
업무수첩이 정상 동작 중이라면 다시 설정할 필요가 없습니다. 다시 연결하면 Notion에 새 업무 DB가 하나 더 만들어질 수 있습니다. 업무수첩으로 돌아가기
1. Notion 토큰 만들기

이 단계만 PC의 Notion 앱 또는 웹에서 진행하는 것을 권장합니다.
휴대폰보다 설정 메뉴를 찾기 쉽습니다.

  1. Notion 왼쪽 아래의 워크스페이스 이름 클릭 → 설정
  2. 설정 창 왼쪽 메뉴를 아래로 내려 개발자 선택
  3. 개인 사용 권한 토큰(PAT)에서 새 토큰 선택
  4. 토큰 이름은 업무수첩처럼 알아보기 쉽게 적고, 사용할 워크스페이스를 선택한 뒤 Notion API 권한 켜기
  5. 토큰을 만든 뒤 표시되는 ntn_... 값을 복사하고, 업무수첩을 사용할 기기의 아래 2번 칸에 붙여넣기

헷갈리기 쉬운 점: 왼쪽 메뉴의 연결이 아니라 개발자로 들어가야 합니다. 개발자 메뉴가 안 보이면 왼쪽 설정 메뉴를 아래로 스크롤하세요. 개발자 화면 위쪽의 ‘개발자 기능 활성화’ 스위치는 건드리지 않아도 됩니다. 아래의 개인 사용 권한 토큰(PAT)에서 ‘새 토큰’만 누르면 됩니다.

Notion 공식 토큰 안내 보기

방금 만든 토큰 전체를 붙여넣으세요. 보통 ntn_으로 시작합니다. 토큰은 비밀번호와 같으므로 다른 사람에게 보내거나 메신저에 남기지 마세요.

평소 업무를 가장 많이 기록할 회사나 기관 이름을 적으세요. 개인 업무용이면 ‘개인’이라고 적으면 됩니다. 나중에 업무를 저장할 때 ‘개인’이나 ‘기타’로 바꿔 저장할 수도 있습니다.

이 버튼을 누르면 Notion에 업무수첩 전용 페이지와 업무 저장 DB를 새로 만듭니다. 기존 Notion 문서는 수정하지 않습니다.

연결 완료 — 이제 설치만 하면 됩니다.

아래 ‘업무수첩 시작’을 누른 뒤 홈 화면에 추가하세요.

Android Chrome: 오른쪽 위 ⋮ → ‘앱 설치’ 또는 ‘홈 화면에 추가’

iPhone Safari: 공유 버튼 → ‘홈 화면에 추가’

Notion에 자동으로 만들어지는 항목
  • 🎙 업무비서 — 업무수첩 전용 상위 페이지
  • 🎙 업무 통합 기록 — 말하거나 입력한 실제 업무가 저장되는 DB
  • 일일 브리핑용 시스템 기록 — 오늘 할 일과 진행 업무를 보여주기 위한 내부 기록
보안 안내

Notion 토큰은 Notion에 접근하는 열쇠입니다. 이 기기의 브라우저에 저장되어 업무를 Notion에 저장할 때 사용됩니다. 개인 휴대폰·개인 PC에서만 사용하고, 토큰을 메신저나 다른 사람에게 보내지 마세요.
