최신

2026. 9. 16.

홈·브리핑·검색·알림·편집

  • 홈 UX 개선 — 앱을 열면 오늘의 브리핑을 먼저 확인하고, 화면 하단 중앙에서 음성 기록을 바로 시작할 수 있게 정리했습니다.
  • 브리핑 4구간 통일 — 오늘의 브리핑과 전체 브리핑을 `지난 것 / 오늘 할 일 / 다가오는 업무 / 기한 없는 업무` 기준으로 통일했습니다.
  • 저장 즉시 반영 — 업무 저장 후 브리핑과 일정이 바로 다시 읽히고, 필요할 때 `브리핑 리셋`으로 최신 상태를 강제로 다시 불러올 수 있게 했습니다.
  • 일정 자동 연결 — 날짜와 시간이 분명한 약속·미팅·방문·통화는 업무 기록과 함께 일정으로 연결되도록 했습니다. 단순 마감 기한은 일정으로 만들지 않습니다.
  • 통합 검색 0.1 — 로그인 사용자가 지난 업무를 키워드로 검색할 수 있는 모바일 검색 화면을 추가했습니다.
  • 알림 확장 — 오전 8:30 오늘 브리핑과 오후 4:30 미완료 업무 Web Push를 추가하고 실제 알림 문구를 즉시 테스트할 수 있게 했습니다.
  • 기록 정제 0.1 — 원문은 그대로 보존하면서 검색과 후속 정리에 사용할 정제 결과를 별도로 관리하는 기반을 추가했습니다.
  • Data Core 업무 편집 — Platform 사용자가 업무명을 수정할 때 예전 Notion 운영자 접근키를 요구하지 않고 자신의 업무만 수정하도록 편집 경로를 분리했습니다.
  • 시작 화면 개선 — 설치 PWA의 시스템 시작 화면과 앱 내부 브랜드 화면을 같은 흰 배경·수첩/마이크 아이콘으로 맞춰 이중 로딩처럼 보이는 느낌을 줄였습니다.
  • 속도·안정성 — 앱 시작, 인증 설정, 브리핑 조회, 정적 자산 캐시, 업무 저장 경로를 단계적으로 단축하고 stale 세션 복구를 보강했습니다.

2026. 9. 15.

로그인·설정·Data Core

  • Google 로그인을 기본 시작 방법으로 추가하고 이메일 로그인도 함께 유지했습니다.
  • 신규 사용자를 위한 첫 화면, 공유 썸네일, 독립 설정 페이지와 앱 설치 메뉴를 추가했습니다.
  • 로그인 후 계정 카드를 숨기고 로그아웃을 설정으로 이동해 홈을 업무 중심으로 단순화했습니다.
  • 신규 Platform 사용자의 첫 진입에서 legacy Notion 접근키 팝업이 나타나지 않도록 정리했습니다.
  • 직접 입력 화면을 텍스트 + 저장 중심으로 단순화하고 브리핑 전체 접기 옵션을 추가했습니다.
  • 업무수첩의 구조화 데이터 기반을 Supabase Data Core 중심으로 전환할 수 있는 Production 준비·활성화 기록을 완료했습니다.

2026. 9. 14.

Platform V1 기반

  • Data Core의 Workspace, 업무기록, 일정, 원본 참조, 후보 데이터와 사용자별 RLS 격리 구조를 구축했습니다.
  • Supabase 로그인 사용자의 Personal Workspace 자동 생성과 Data Core 저장 경로를 추가했습니다.
  • Briefing V2가 Data Core 업무·일정을 읽고 완료/되돌리기를 처리할 수 있게 했습니다.
  • 일정 후보를 실제 일정으로 안전하게 확정하는 공통 경계를 추가했습니다.
  • 통화 처리에서 공통 idempotency, processing job, retry/checkpoint, storage 경계를 재사용하기 시작했습니다.
  • User Acceptance Ready와 모바일 시각 안정성 검사를 도입해 Preview 검수 기준을 강화했습니다.

2026. 9. 13.

제품·모듈 아키텍처

  • 업무수첩 프로젝트 헌장과 모듈 아키텍처 V1을 확정했습니다.
